# 🛒 Панель управления магазином товаров (Python HTTP Server + Bootstrap 5)

Простая и надежная модульная система управления интернет-магазином. Проект написан на чистом Python без использования сторонних веб-фреймворков (Django/Flask) и полностью стилизован с помощью фреймворка **Bootstrap 5**.

---

## 🎯 Соответствие критериям оценки работы

| Критерий из задания | Как реализовано в проекте |
| :--- | :--- |
| **Определен `.gitignore` со всеми элементами** | В корне проекта создан файл `.gitignore`, который скрывает папки `.idea`, `venv/`, `__pycache__/`, `env/` и файлы `*.sqlite*`. |
| **Присутствуют ключевые блоки (хедер, боди, футер)** | Каркас `templates/base_menu.html` содержит теги `<header>` (боковое меню), `<main>` (зона контента) и `<footer>` (подвал сайта). |
| **Использован Bootstrap для верстки** | Все страницы верстки переведены на сетку и компоненты Bootstrap 5 (`row`, `col`, `card`, `nav-pills`). Кастомные стили удалены. |
| **Создано приложение для страницы "Контакты"** | Доступен маршрут `/contacts` с рабочей формой обратной связи. |
| **Реализован дополнительный функционал (404)** | При вводе любого некорректного адреса сервер возвращает статус `404 Not Found` и отображает красивую страницу `templates/page_404.html`. |
| **Возвращается HTML с правильным Content-Type** | Сервер отправляет заголовок `Content-Type: text/html; charset=utf-8`, что исключает проблемы с кодировкой (иероглифы). |
| **Использование контекстных менеджеров** | Чтение всех шаблонов страниц из папки `templates/` происходит строго через конструкцию `with open(..., 'r', encoding='utf-8') as file:`. |
| **Сервер принимает POST-запросы** | При отправке формы со страницы контактов данные обрабатываются методом `do_POST`, декодируются и без ошибок выводятся в терминал. |

## 📂 Структура файлов проекта

```text
my_project/
│
├── .gitignore             # Исключения для Git (настройки IDE, кэш Python)
├── README.md              # Документация проекта (этот файл)
├── server.py              # Исполняемый файл сервера на чистом Python
│
└── templates/             # Директория с шаблонами страниц сайта
    ├── base_menu.html     # Мастер-шаблон (Общее меню, подвал, подключение Bootstrap)
    ├── main.html          # Главная страница (Сетка из 3 товаров)
    ├── categories.html    # Каталог товаров (Сетка 2х3 из 6 товаров)
    ├── orders.html        # История заказов пользователя
    ├── contacts.html      # Форма обратной связи для отправки POST-запросов
    └── page_404.html      # Страница ошибки при переходе по неверному адресу
```

## 💻 Инструкция по локальному запуску

### 1. Подготовка окружения
Убедитесь, что у вас установлен Python версии 3.7 или выше. Дополнительные библиотеки устанавливать не требуется.

### 2. Запуск сервера
Откройте терминал (или консоль PyCharm) в папке проекта и выполните команду:
```bash
python server.py
```
В консоли должно появиться сообщение:
`Сервер запущен по адресу: http://localhost:8000`

### 3. Просмотр в браузере
Откройте любой современный браузер (например, Google Chrome) и перейдите по адресу:
👉 **[http://localhost:8000](http://localhost:8000)**

*Важно: Не открывайте файлы из папки `templates` двойным кликом мыши напрямую через Проводник, так как без запущенного Python-сервера динамическая сборка шаблонов работать не будет.*

## 🛠 Проверка POST-запроса
1. Перейдите на вкладку **«Контакты»**.
2. Заполните поля формы (Имя, Почта, Сообщение).
3. Нажмите кнопку **«Отправить сообщение»**.
4. Страница отобразит успешный статус отправки, а в терминале запущенного сервера отобразятся переданные данные:
```text
================================================
=== [POST] ПОЛУЧЕНЫ ДАННЫЕ ИЗ ФОРМЫ КОНТАКТОВ ===
================================================
Поле 'name': ['Ваше Имя']
Поле 'email': ['user@example.com']
Поле 'message': ['Текст тестового сообщения']
================================================
```
